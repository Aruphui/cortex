What is RAG and Why Azure AI Search?

Retrieval-Augmented Generation (RAG) is a design pattern that grounds an LLM's response in up-to-date, private, or domain-specific knowledge by retrieving relevant chunks of text from a knowledge base and injecting them into the prompt before generation. This eliminates hallucinations on facts the LLM was never trained on.

🧠 Pure LLM

Only knows training data. Cannot answer about your internal documents, recent events, or private data.

❌ No grounding

🔍 RAG + LLM

Searches your knowledge base first, then feeds relevant passages to the LLM alongside the question.

✅ Grounded answers

☁️ Azure AI Search

Managed cloud search with BM25 keyword, vector (HNSW), hybrid search, and semantic reranking built-in.

Enterprise-grade

Why Choose Azure AI Search for RAG?

4.3 Vector Field Configuration

Vector fields need a VectorSearchConfiguration that specifies the algorithm and its parameters. Azure AI Search uses HNSW (Hierarchical Navigable Small World) for Approximate Nearest Neighbour search.

ParameterDescriptionRecommended Value
dimensionsVector size. Must match your embedding model output.3072 (text-embedding-3-large), 1536 (ada-002)
mHNSW: max connections per node. Higher = better recall, more memory.4 (default) → 16 for high-recall use cases
ef_constructionBuild-time candidate list size. Higher = slower indexing, better quality.400 (default) → 800 for high quality
ef_searchQuery-time candidate list size. Higher = better recall, slower query.500 (default)

Document Chunking Strategies

Chunking determines the granularity of your search. Chunks that are too large overwhelm the LLM's context window. Chunks that are too small lose context. Finding the sweet spot is critical.

Fixed-Size Chunking

Split every N tokens with an M-token overlap. Simple, predictable. Best for uniform documents.

Overlap: 10–15%

Sentence / Paragraph

Split on natural language boundaries. Preserves semantic coherence within each chunk.

Recommended default

Semantic Chunking

Split where the embedding distance between consecutive sentences spikes — topic change detection.

Higher compute cost

Hierarchical

Store both parent (section) and child (sentence) chunks. Retrieve child, send parent to LLM.

Best recall + context

Fixed-Size Chunking with Overlap (Python)

import tiktoken

def chunk_text(text: str, chunk_size: int = 512, overlap: int = 64, model: str = "cl100k_base") -> list[str]:
    """Split text into token-aware chunks with overlap."""
    enc    = tiktoken.get_encoding(model)
    tokens = enc.encode(text)
    chunks = []
    start  = 0

    while start < len(tokens):
        end        = min(start + chunk_size, len(tokens))
        chunk_toks = tokens[start:end]
        chunks.append(enc.decode(chunk_toks))
        if end == len(tokens):
            break
        start += chunk_size - overlap  # slide window with overlap

    return chunks

# Usage
text   = "Your long document text goes here..."
chunks = chunk_text(text, chunk_size=512, overlap=64)
print(f"Created {len(chunks)} chunks")
⚠️
Golden Rule of Chunking

Your chunk size should be significantly smaller than the LLM's context window. With GPT-4o (128K tokens) and top-K=5, keep chunks ≤ 1024 tokens each to leave room for the system prompt and conversation history.

Recommended Chunk Sizes by Use Case

Use CaseChunk Size (tokens)OverlapTop-K

Technical Documentation512 – 102464 – 128 tokens5 – 8
Legal / Contracts1024128 tokens3 – 5
Research Papers512 (abstract + sections)64 tokens5

Generating Embeddings with Azure OpenAI

Embeddings convert text into high-dimensional vectors (floats) that capture semantic meaning. Similar content will have vectors close together in the embedding space.

Supported Embedding Models

ModelDimensionsMax Input TokensNotes
text-embedding-3-large3072 (or custom)8191Best quality — recommended for production
text-embedding-3-small1536 (or custom)8191Faster, cheaper, nearly as good
text-embedding-ada-00215368191Legacy — use v3 models for new projects
 
from openai import AzureOpenAI
import os, time

oai_client = AzureOpenAI(
    api_key=os.getenv("AZURE_OPENAI_API_KEY"),
    api_version="2024-02-01",
    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT")
)

def get_embedding(text: str, model: str = "text-embedding-3-large") -> list[float]:
    """Generate an embedding vector for a text string."""
    text = text.replace("\n", " ").strip()
    if not text:
        raise ValueError("Cannot embed empty text.")
    response = oai_client.embeddings.create(input=[text], model=model)
    return response.data[0].embedding


def get_embeddings_batch(texts: list[str], model: str = "text-embedding-3-large", batch_size: int = 16) -> list[list[float]]:
    """Embed a list of texts in batches (respects API rate limits)."""
    all_embeddings = []
    for i in range(0, len(texts), batch_size):
        batch = texts[i : i + batch_size]
        resp  = oai_client.embeddings.create(input=batch, model=model)
        all_embeddings.extend([item.embedding for item in resp.data])
        time.sleep(0.1)  # avoid throttling
    return all_embeddings
ℹ️
Dimension Reduction

text-embedding-3-large supports custom dimensions. You can request fewer dimensions (e.g., 1024 or 512) with no API change — just set dimensions=1024 in the call. Fewer dimensions = smaller index, faster queries, slightly lower recall.

Saving Chunks to the Search Index

With chunked text and their embeddings ready, you upload them to Azure AI Search as documents using the upload_documents (or merge_or_upload_documents) action. Azure supports batch uploads of up to 1,000 documents per batch (max 16 MB per request). 

from azure.search.documents import SearchClient
from azure.core.credentials import AzureKeyCredential
from datetime import datetime, timezone
import hashlib, os

search_client = SearchClient(
    endpoint=os.getenv("AZURE_SEARCH_ENDPOINT"),
    index_name=os.getenv("AZURE_SEARCH_INDEX_NAME"),
    credential=AzureKeyCredential(os.getenv("AZURE_SEARCH_KEY"))
)

def make_chunk_id(source_file: str, chunk_index: int) -> str:
    """Deterministic ID so re-indexing is idempotent."""
    raw = f"{source_file}_{chunk_index}"
    return hashlib.md5(raw.encode()).hexdigest()

def index_document_chunks(
    chunks: list[str],
    embeddings: list[list[float]],
    source_file: str,
    title: str,
    category: str = "general",
    tags: list[str] = None,
    author: str = "",
    department: str = "",
    language: str = "en",
    batch_size: int = 100
):
    """Build document dicts and upload to Azure AI Search."""
    now = datetime.now(timezone.utc).isoformat()
    documents = []

    for i, (chunk, vector) in enumerate(zip(chunks, embeddings)):
        doc = {
            "id":               make_chunk_id(source_file, i),
            "content":         chunk,
            "content_vector":  vector,
            "title":           title,
            "source_file":     source_file,
            "source_url":      f"https://yourstorage.blob.core.windows.net/docs/{source_file}",
            "section":         "",        # populate if you parsed headings
            "page_number":     0,         # populate from PDF parser
            "chunk_index":     i,
            "token_count":     len(chunk.split()),  # approximate; use tiktoken for exact
            "category":        category,
            "tags":            tags or [],
            "language":        language,
            "author":          author,
            "department":      department,
            "created_at":      now,
            "last_modified":   now,
            "confidence_score": 1.0
        }
        documents.append(doc)

    # Upload in batches
    total_uploaded = 0
    for i in range(0, len(documents), batch_size):
        batch   = documents[i : i + batch_size]
        results = search_client.merge_or_upload_documents(documents=batch)
        succeeded = sum(1 for r in results if r.succeeded)
        total_uploaded += succeeded
        print(f"  Batch {i//batch_size + 1}: {succeeded}/{len(batch)} documents uploaded.")

    print(f"✅ Total: {total_uploaded}/{len(documents)} chunks indexed.")
    return total_uploaded


# ── Full ingestion workflow ────────────────────────────
raw_text   = open("my_document.txt").read()
chunks     = chunk_text(raw_text, chunk_size=512, overlap=64)
embeddings = get_embeddings_batch(chunks)

index_document_chunks(
    chunks=chunks,
    embeddings=embeddings,
    source_file="my_document.txt",
    title="My Technical Document",
    category="technical",
    tags=["azure", "ai", "search"],
    author="Engineering Team",
    department="R&D"

Querying the Search Index

Azure AI Search supports four search modes. For RAG, Hybrid Search with Semantic Reranking is the gold standard — it combines the literal precision of BM25 with the semantic understanding of vector search, then reranks with a cross-encoder model.

Hybrid + Semantic RerankingHybrid + L2 cross-encoder rerankerHighest precision✅✅✅ Best

8.3 Hybrid Search + Semantic Reranking (Recommended)

from azure.search.documents.models import VectorizedQuery, QueryType, QueryCaptionType, QueryAnswerType

def hybrid_search(query: str, top_k: int = 5, filter_expr: str = None) -> list[dict]:
    """
    Perform hybrid search (BM25 + vector) with semantic reranking.
    Returns the top-k most relevant chunks.
    """
    query_vector = get_embedding(query)

    results = search_client.search(
        search_text=query,                       # BM25 keyword search
        vector_queries=[
            VectorizedQuery(
                vector=query_vector,             # vector search
                k_nearest_neighbors=50,         # fetch more candidates for reranker
                fields="content_vector"
            )
        ],
        query_type=QueryType.SEMANTIC,           # enable semantic reranking
        semantic_configuration_name="semantic-config",
        query_caption=QueryCaptionType.EXTRACTIVE,
        query_answer=QueryAnswerType.EXTRACTIVE,
        filter=filter_expr,                      # optional OData filter
        select=["id", "content", "title", "source_file", "source_url",
                "page_number", "chunk_index", "category"],
        top=top_k
    )

    chunks = []
    for r in results:
        chunks.append({
            "id":          r["id"],
            "content":     r["content"],
            "title":       r.get("title", ""),
            "source_file": r.get("source_file", ""),
            "source_url":  r.get("source_url", ""),
            "page_number": r.get("page_number", 0),
            "score":       r["@search.reranker_score"]  # semantic reranker score (0-4)
        })
    return chunks

8.4 Filtering with Metadata

Use OData filter expressions to restrict search to specific subsets of your index:

# Only search within the "legal" category, English documents, after 2025
filter_expr = "category eq 'legal' and language eq 'en' and created_at ge 2025-01-01T00:00:00Z"
chunks = hybrid_search("What are the termination clauses?", filter_expr=filter_expr)

# Filter by department + tag
filter_expr = "department eq 'HR' and tags/any(t: t eq 'onboarding')"
chunks = hybrid_search("What is the new employee process?", filter_expr=filter_expr)

# Filter by confidence score (exclude low-quality OCR results)
filter_expr = "confidence_score ge 0.85"
chunks = hybrid_search("Show me extraction results", filter_expr=filter_expr)

Connecting Search Results to an LLM (The RAG Step)

Retrieved chunks become the context injected into the system prompt. The LLM is instructed to answer only from that context, enabling grounded, citation-rich responses. 

def build_rag_prompt(question: str, chunks: list[dict]) -> list[dict]:
    """Build the messages array for an OpenAI chat completion."""
    context_parts = []
    for i, chunk in enumerate(chunks, 1):
        context_parts.append(
            f"[Source {i}: {chunk['title']} | {chunk['source_file']} | Page {chunk['page_number']}]\n"
            f"{chunk['content']}"
        )
    context = "\n\n---\n\n".join(context_parts)

    system_prompt = f"""You are a helpful assistant that answers questions based ONLY on the provided context.
If the answer is not in the context, say "I don't have enough information to answer this question."
Always cite the source number (e.g., [Source 1]) when referencing information.

Context:
{context}"""

    return [
        {"role": "system", "content": system_prompt},
        {"role": "user",   "content": question}
    ]


def rag_answer(question: str, filter_expr: str = None, top_k: int = 5) -> dict:
    """Full RAG pipeline: search → prompt → LLM answer."""
    # Step 1: Retrieve
    chunks   = hybrid_search(question, top_k=top_k, filter_expr=filter_expr)
    if not chunks:
        return {"answer": "No relevant documents found.", "sources": []}

    # Step 2: Augment
    messages = build_rag_prompt(question, chunks)

    # Step 3: Generate
    response = oai_client.chat.completions.create(
        model=os.getenv("AZURE_OPENAI_CHAT_DEPLOYMENT"),
        messages=messages,
        temperature=0.1,   # low temperature for factual RAG
        max_tokens=1024
    )

    return {
        "answer":  response.choices[0].message.content,
        "sources": [{"title": c["title"], "url": c["source_url"], "page": c["page_number"]} for c in chunks]
    }

# Test it
result = rag_answer("What is the company's remote work policy?", filter_expr="category eq 'HR'")
print(result["answer"])
print("Sources:", result["sources"])

Document-Level Security (Row-Level Filtering)

Azure AI Search does not support native row-level security out of the box, but you can implement it by storing a permitted_groups field (Collection of strings) and filtering queries based on the authenticated user's group memberships: 

# During indexing, store who can access this document
doc["permitted_groups"] = ["engineers", "admins"]

# During querying, filter to user's groups (fetched from Azure AD)
user_groups   = ["engineers"]   # from Microsoft Graph API
group_filter  = " or ".join([f"permitted_groups/any(g: g eq '{g}')" for g in user_groups])
results       = search_client.search(search_text=query, filter=group_filter, top=5)

Scoring Profiles & Relevance Tuning

Scoring profiles let you boost results based on field values or document freshness — separate from semantic reranking. This is applied at the BM25/keyword stage. 

from azure.search.documents.indexes.models import (
    ScoringProfile, TextWeights, FreshnessScoringFunction,
    FreshnessScoringParameters, ScoringFunctionInterpolation
)

scoring_profile = ScoringProfile(
    name="freshness-boost",
    text_weights=TextWeights(weights={
        "title":   3.0,   # title matches count 3x more
        "content": 1.0,
        "tags":    2.0    # tag matches count 2x more
    }),
    functions=[
        FreshnessScoringFunction(
            field_name="last_modified",
            boost=2.0,
            parameters=FreshnessScoringParameters(boosting_duration="P30D"),  # boost last 30 days
            interpolation=ScoringFunctionInterpolation.LINEAR
        )
    ]
)

Cost Optimisation Tips

  • Set retrievable=False on vector fields — you never need raw floats in results.
  • Use text-embedding-3-small with dimensions=512 for non-critical corpora — 5× cheaper than large.
  • Enable Incremental enrichment cache in Skillsets to avoid re-processing unchanged documents.
  • Use query-only keys (or Search Index Data Reader role) for application queries.
  • Compress old/archived indexes using quantization (scalar quantization, available in newer API versions).
⚠️
Semantic Reranking has a monthly quota

On Standard S1, you get 1,000 free semantic calls/month, then pay per use. Only apply semantic reranking at the final user-facing query layer, not in internal enrichment pipelines.

End-to-End RAG Pipeline — Complete Runnable Script

Below is a single, self-contained Python script that wires together everything covered in this article.

"""
rag_pipeline.py — End-to-End RAG with Azure AI Search + Azure OpenAI
Run: python rag_pipeline.py
"""
import os, hashlib, time
from datetime import datetime, timezone
from dotenv import load_dotenv
import tiktoken
from openai import AzureOpenAI
from azure.core.credentials import AzureKeyCredential
from azure.search.documents import SearchClient
from azure.search.documents.indexes import SearchIndexClient
from azure.search.documents.indexes.models import (
    SearchIndex, SearchField, SimpleField, SearchableField,
    SearchFieldDataType, VectorSearch, HnswAlgorithmConfiguration,
    HnswParameters, VectorSearchProfile, SemanticConfiguration,
    SemanticSearch, SemanticPrioritizedFields, SemanticField
)
from azure.search.documents.models import VectorizedQuery, QueryType

load_dotenv()

# ══ Clients ══════════════════════════════════════════
oai = AzureOpenAI(
    api_key=os.getenv("AZURE_OPENAI_API_KEY"),
    api_version="2024-02-01",
    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT")
)
cred         = AzureKeyCredential(os.getenv("AZURE_SEARCH_KEY"))
idx_client   = SearchIndexClient(os.getenv("AZURE_SEARCH_ENDPOINT"), cred)
srch_client  = SearchClient(os.getenv("AZURE_SEARCH_ENDPOINT"),
                             os.getenv("AZURE_SEARCH_INDEX_NAME"), cred)
EMBED_MODEL  = os.getenv("AZURE_OPENAI_EMBED_DEPLOYMENT", "text-embedding-3-large")
CHAT_MODEL   = os.getenv("AZURE_OPENAI_CHAT_DEPLOYMENT",  "gpt-4o")
INDEX_NAME   = os.getenv("AZURE_SEARCH_INDEX_NAME",       "rag-knowledge-base")

# ══ 1. Create Index ═══════════════════════════════════
def create_index():
    index = SearchIndex(
        name=INDEX_NAME,
        fields=[
            SimpleField(   name="id",             type=SearchFieldDataType.String,  key=True,  retrievable=True),
            SearchableField(name="content",       type=SearchFieldDataType.String,          retrievable=True, analyzer_name="en.microsoft"),
            SearchableField(name="title",         type=SearchFieldDataType.String,          retrievable=True, filterable=True),
            SearchField(   name="content_vector", type=SearchFieldDataType.Collection(SearchFieldDataType.Single),
                           searchable=True, retrievable=False,
                           vector_search_dimensions=3072, vector_search_profile_name="hnsw-profile"),
            SimpleField(   name="source_file",   type=SearchFieldDataType.String,  filterable=True,  retrievable=True),
            SimpleField(   name="source_url",    type=SearchFieldDataType.String,               retrievable=True),
            SimpleField(   name="category",      type=SearchFieldDataType.String,  filterable=True,  facetable=True, retrievable=True),
            SimpleField(   name="page_number",   type=SearchFieldDataType.Int32,   filterable=True,  sortable=True,  retrievable=True),
            SimpleField(   name="chunk_index",   type=SearchFieldDataType.Int32,   filterable=True,  sortable=True,  retrievable=True),
            SimpleField(   name="last_modified", type=SearchFieldDataType.DateTimeOffset, filterable=True, sortable=True, retrievable=True),
            SearchField(   name="tags",          type=SearchFieldDataType.Collection(SearchFieldDataType.String),
                           filterable=True, facetable=True, retrievable=True),
        ],
        vector_search=VectorSearch(
            algorithms=[HnswAlgorithmConfiguration(name="hnsw", parameters=HnswParameters(m=16, ef_construction=800, metric="cosine"))],
            profiles=[VectorSearchProfile(name="hnsw-profile", algorithm_configuration_name="hnsw")]
        ),
        semantic_search=SemanticSearch(configurations=[
            SemanticConfiguration(name="semantic-config",
                prioritized_fields=SemanticPrioritizedFields(
                    title_field=SemanticField(field_name="title"),
                    content_fields=[SemanticField(field_name="content")]))
        ])
    )
    idx_client.create_or_update_index(index)
    print(f"✅ Index '{INDEX_NAME}' ready.")

# ══ 2. Chunk ══════════════════════════════════════════
def chunk_text(text, chunk_size=512, overlap=64):
    enc    = tiktoken.get_encoding("cl100k_base")
    tokens = enc.encode(text)
    chunks, start = [], 0
    while start < len(tokens):
        end = min(start + chunk_size, len(tokens))
        chunks.append(enc.decode(tokens[start:end]))
        if end == len(tokens): break
        start += chunk_size - overlap
    return chunks

# ══ 3. Embed ══════════════════════════════════════════
def embed_batch(texts, batch_size=16):
    all_vecs = []
    for i in range(0, len(texts), batch_size):
        resp = oai.embeddings.create(input=texts[i:i+batch_size], model=EMBED_MODEL)
        all_vecs.extend([x.embedding for x in resp.data])
        time.sleep(0.1)
    return all_vecs

# ══ 4. Index ══════════════════════════════════════════
def ingest(text, source_file, title, category="general", tags=None):
    chunks     = chunk_text(text)
    embeddings = embed_batch(chunks)
    now        = datetime.now(timezone.utc).isoformat()
    docs = [{
        "id":             hashlib.md5(f"{source_file}_{i}".encode()).hexdigest(),
        "content":        c,
        "content_vector": v,
        "title":          title,
        "source_file":    source_file,
        "source_url":     f"https://storage.example.com/{source_file}",
        "category":       category,
        "tags":           tags or [],
        "page_number":    0,
        "chunk_index":    i,
        "last_modified":  now
    } for i, (c, v) in enumerate(zip(chunks, embeddings))]
    srch_client.merge_or_upload_documents(docs)
    print(f"✅ Indexed {len(docs)} chunks from '{source_file}'")

# ══ 5. Search ═════════════════════════════════════════
def search(query, top=5, filter_expr=None):
    vec = oai.embeddings.create(input=[query], model=EMBED_MODEL).data[0].embedding
    res = srch_client.search(
        search_text=query,
        vector_queries=[VectorizedQuery(vector=vec, k_nearest_neighbors=50, fields="content_vector")],
        query_type=QueryType.SEMANTIC,
        semantic_configuration_name="semantic-config",
        filter=filter_expr, top=top,
        select=["id", "content", "title", "source_file", "source_url", "page_number"]
    )
    return [dict(r) for r in res]

# ══ 6. RAG Answer ═════════════════════════════════════
def ask(question, filter_expr=None):
    chunks  = search(question, filter_expr=filter_expr)
    context = "\n\n---\n\n".join([f"[Source {i+1}: {c['title']}]\n{c['content']}" for i, c in enumerate(chunks)])
    messages = [
        {"role": "system", "content": f"Answer ONLY from the context below. Cite [Source N].\n\n{context}"},
        {"role": "user",   "content": question}
    ]
    ans = oai.chat.completions.create(model=CHAT_MODEL, messages=messages, temperature=0.1)
    print("\n🤖 Answer:\n", ans.choices[0].message.content)
    print("\n📚 Sources:", [{"title": c["title"], "url": c["source_url"]} for c in chunks])

# ══ Main ══════════════════════════════════════════════
if __name__ == "__main__":
    create_index()
    ingest(open("sample.txt").read(), "sample.txt", "Sample Document", tags=["demo"])
    ask("Summarise the main points of the document.")
